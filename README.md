# Git・GitHub 講座｜第1週 学生用教材

このRepositoryは講義用の**配布ファイル専用**です。受講者は講師のRepositoryをCloneしないでください。

## ダウンロード

**[📦 git-practice-starter.zip をダウンロード](https://github.com/ryuusuraimu/test-github/raw/refs/heads/main/git-practice-starter.zip)**

## 授業のはじめ方

1. 上のZIPをダウンロードして展開します。
2. 展開された `git-practice` フォルダーを確認します。その中には `index.html` が1つあります。
3. VS Codeを開き、`ファイル > フォルダーを開く` から **git-practice** を選びます。
4. `index.html` に「自己紹介」「所属：情報工学科」「名前：サンプル」があることを確認します。
5. 講義資料の指示に従って、`Git Repositoryを初期化` → `Stage` → `Commit` → **自分のGitHubアカウントへPrivate Repositoryとして公開** してください。

### 注意

- このZIPに `.git` フォルダーやGit履歴は入っていません。
- **この配布Repository自体にPushしない**でください。
- 自分の名前などを記入する場合、GitHubへの公開設定をPrivateにしてください。
- コードの完成版ではなく、学習開始前のファイルのみを配布しています。

配布ZIP内容：
```text
git-practice/
└── index.html
```
